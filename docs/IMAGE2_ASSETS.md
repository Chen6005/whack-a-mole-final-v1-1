# Image 2 Asset Record

All 28 production images were generated with Image 2 and stored locally under `src/assets/images/`. Isolated sprites were generated on a flat magenta chroma-key background, processed locally into transparent PNG files and resized for mobile delivery. Backgrounds were generated as full portrait scenes.

## Style

Cute 3D cartoon arcade game style.
Transparent background for isolated assets.
No text baked into reusable UI assets unless necessary.

## Prompt Direction

Each asset used a production prompt with:

- intended mobile-game use
- cute polished 3D garden arcade direction
- centered readable composition
- no watermark and no baked-in text
- portrait edge decoration for backgrounds
- flat `#ff00ff` chroma-key background for transparent sprites

All required filenames were verified after generation and local processing.
