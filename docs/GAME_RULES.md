# Game Rules

## Core Rule

Tap or click moles before they disappear.

## Round Modes

- Quick: 30 seconds
- Challenge: 45 seconds
- Normal: 60 seconds

## Target Types

| Target | Effect |
|---|---|
| Normal Mole | +10 points |
| Golden Mole | +30 points |
| Time Mole | +5 seconds and +5 points |
| Bomb Mole | -20 points and breaks combo |
| Shield Mole | Requires 2 hits, then +25 points |

## Combo

Consecutive correct hits increase combo.
Mistakes reset combo.

## Difficulty

The game becomes faster as time decreases.

## End Condition

The game ends when the timer reaches zero.
