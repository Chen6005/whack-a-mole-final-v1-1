## 3. Game Concept

Theme:
A cute, polished, high-energy garden arcade game.

Core gameplay:
Moles pop out from holes randomly. The player taps or clicks them before they disappear. Correct hits increase score. Special targets create variation. Bomb targets punish careless tapping. The round ends when the timer reaches zero.

---

## 4. Main Game Rules

### 4.1 Round Length

Default round length:

- 60 seconds for Normal Mode
- 45 seconds for Challenge Mode
- 30 seconds for Quick Mode

The first release must include all three modes.

### 4.2 Board

Use a 3x3 board by default.

On very small mobile screens, preserve the 3x3 layout but reduce hole size.

### 4.3 Target Types

Implement at least these targets:

1. Normal Mole
   - +10 points

2. Golden Mole
   - +30 points
   - Lower appearance probability

3. Time Mole
   - +5 seconds
   - +5 points

4. Bomb Mole
   - -20 points
   - Small screen shake
   - Does not end the game

5. Shield Mole / Helmet Mole
   - Requires 2 hits
   - +25 points after second hit

### 4.4 Difficulty Progression

The game starts slow and becomes faster.

Difficulty must affect:

- Mole visible duration
- Spawn interval
- Probability of multiple simultaneous targets
- Probability of special targets

Example progression:

- 60s–45s remaining: easy
- 44s–25s remaining: medium
- 24s–10s remaining: hard
- 9s–0s remaining: frenzy

### 4.5 Scoring

Score must be visible at all times.

Also track:

- Current score
- High score
- Combo count
- Accuracy
- Hits
- Misses

### 4.6 Combo System

If player hits targets consecutively without hitting empty holes or bombs:

- 3 combo: small bonus
- 5 combo: visual effect
- 10 combo: score multiplier for a short period

### 4.7 Miss Rules

A miss means tapping/clicking an empty hole or hitting a bomb.

Misses break combo.

### 4.8 Game End

When time reaches zero:

Show result screen with:

- Final score
- High score
- Accuracy
- Highest combo
- Rank:
  - S: excellent
  - A: very good
  - B: good
  - C: practice more
- Buttons:
  - Play Again
  - Change Mode
  - Back to Home

## 8. Implementation Requirements

### 8.1 State Management

Use React state and reducer pattern.

Game state must include:

- screen
- mode
- score
- highScore
- timeRemaining
- isPaused
- activeHoles
- combo
- maxCombo
- hits
- misses
- accuracy
- soundEnabled
- effectsEnabled
- reducedMotion

### 8.2 Timing

Use safe timer logic.

Avoid memory leaks.

When paused:

- stop countdown
- stop spawning
- freeze active targets

When resumed:

- continue correctly

### 8.3 Target Spawn Logic

Moles must appear randomly.

Avoid impossible overlap bugs.

Do not spawn the same target repeatedly in a visually boring pattern.

Allow multiple active targets during later difficulty.

### 8.4 Animation

Implement:

- Mole pop-up animation
- Hit squash animation
- Score floating text
- Bomb shake effect
- Combo burst effect
- Smooth screen transitions

Respect reduced motion setting.

### 8.5 Responsive Layout

Must work on:

- iPhone-sized mobile screens
- iPad/tablet
- desktop browser

Rules:

- No white bars on top/bottom in fullscreen mobile browser layout.
- Use min-height: 100dvh where appropriate.
- Board must stay visible.
- Rules screen must scroll correctly.
- Buttons must be touch-friendly.

### 8.6 Accessibility

Implement:

- Button aria-labels
- Keyboard start/restart support
- Visible focus states
- Sufficient contrast
- Reduced motion setting
